# СМО «Сервис распределения заказов Яндекс Такси»

## Описание Варианта

**Расшифровка кода варианта:** `ИБ ИЗ1 ПЗ1 Д1ОЗ1 Д1ОО3 Д2П2 Д2Б3 ОР2 ОД2`

| Параметр | Код | Описание |
| :--- | :--- | :--- |
| **Источник** | `ИБ` | Бесконечный источник (число заявок не ограничено) |
| **Закон генерации** | `ИЗ1` | Экспоненциальный закон распределения интервалов поступления заявок  |
| **Прибор** | `ПЗ1` | Экспоненциальный закон распределения времени обслуживания  |
| **Дисциплина записи** | `Д1ОЗ1` | Запись в первое свободное место по кольцу, начиная с указателя УБ |
| **Дисциплина отказа** | `Д1ОО3` | При переполнении буфера новая заявка встает на место самой старой по времени создания |
| **Выбор прибора** | `Д2П2` | Выбор свободного прибора по кольцу, начиная с указателя УП |
| **Выбор заявки** | `Д2Б3` | Выбор ближайшей заявки из буфера по кольцу, начиная с указателя УВ |
| **Отображение результатов** | `ОР2` | Вывод итоговой сводной таблицы статистических характеристик |
| **Отображение деталей** | `ОД2` | Пошаговый режим с отображением календаря событий, состояния буфера, приборов и указателей |

---

### Основные компоненты:
* **`Source`** — источник заявок на поездки.
* **`Buffer`** — кольцевой буфер ограниченной емкости.
* **`Device`** — автомобиль/водитель (прибор обслуживания).
* **`PlacementDispatcher`** — реализует логику дисциплин `Д1ОЗ1` и `Д1ОО3`.
* **`SelectionDispatcher`** — реализует логику дисциплин `Д2П2` и `Д2Б3`.
* **`EventCalendar`** — очередь с приоритетом для хранения будущих событий (`REQUEST_GENERATED`, `DEVICE_FINISHED`).
* **`Statistic`** — аккумулирует счетчики и суммарные временные интервалы для расчета статистических характеристик.
